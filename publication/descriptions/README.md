# Localized Chrome Web Store descriptions

This folder contains one long-form store description for every locale declared under `/_locales`.

The files use Chrome locale identifiers. Paste each file into the matching language entry in the Chrome Web Store dashboard. Keep the extension name and short description synchronized with the corresponding `_locales/<locale>/messages.json` file.

Descriptions intentionally use natural localized search phrases such as Facebook Messenger cleanup, bulk delete conversations, archive chats, restore archived chats, and Chrome extension. They avoid unsupported claims, keyword stuffing, and promises that the extension deletes individual messages inside a conversation.
